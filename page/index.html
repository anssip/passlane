passlane approvals

This is the passlane approval page: the Phase 0 approver before the iOS app exists (see the passlane repository and crates/passlane-approval/SPEC.md).

You normally land here through a link passlane printed:

  • /enroll.html#… — one-time enrollment of this device's ECDH key and passkey (passlane approvals enroll on the computer). The link material rides the URL fragment, which is never sent to this site.
  • /approve.html#… — an approval request sealed to the key enrolled here. Approve with the passkey, paste the reply back into the terminal. Requests to open, save or enroll a phone-held key (passlane hwkey add --phone on the computer) are answered with the HMAC this device holds for that vault; enrollment shows a recovery sheet first.
  • /pair.html#… — no page is served here: that link pairs the iOS app (passlane approvals pair on the computer), and iOS routes it to the app through this domain's apple-app-site-association. The pairing secret and the request envelope ride the fragment all the same.

No secrets reach this site's server: everything sensitive travels in the URL fragment and inside end-to-end encrypted envelopes whose keys are pinned between your terminal and this device at enrollment.
